隐私政策

生效日期：2026年7月6日
服务名称：雨天信箱（RainMail）
服务地址：https://rainmail.techccy.dpdns.org

雨天信箱（RainMail）是由TechCCY运营的匿名情绪交互平台。我们深知隐私的重要性，本政策说明我们如何收集、使用、存储和保护您的信息。除匿名投递外，本服务还提供可选的注册账号、情感信件投递、回复通知等功能。请仔细阅读，使用本服务即表示您同意本政策。

一、我们收集的信息

为保障服务正常运行和安全，我们会收集以下信息：

1.1 您主动提交的内容

  • 账号信息（注册用户）：电子邮箱（用于登录与邮件通知）、用户名（可选，缺省时取邮箱前缀）、密码（仅以单向哈希存储，我们不存储明文密码）、由 IP 反查得到的所在城市。
  • 消息内容：您在晴天投递的文字消息（最多500字），存储于境外服务器数据库，用于在目标城市降雨时向其他用户展示，保留期限无固定期限。
  • 情感信件：投递类型（公开 / 指定收件人 / 随机已验证用户）、收件人邮箱（可选）、投递选项等。
  • 回复内容：您对他人的文字回复（最多500字）。
  • 联系邮箱（可选）：匿名投递时您可选择填写的回复通知邮箱。

1.2 自动收集的技术信息

信息类型 收集方式 使用目的 保留期限
IP地址 服务器自动记录 防止滥用、安全审计、所在城市反查 30天后自动删除
User-Agent 浏览器自动发送 优化服务兼容性 会话结束后删除
访问时间/页面 服务器日志 故障排查 30天后自动删除

1.3 第三方服务收集或处理的信息

  • Cloudflare Turnstile：用于人机验证，防止机器人滥用。验证数据由 Cloudflare 处理，详见 Cloudflare隐私政策。
  • 和风天气 API：仅传输城市ID（如101280101，广州）用于获取天气状态，不传输任何用户个人信息。
  • ip-api.com：将您的 IP 地址反查为城市名称（用于天气展示与本地化）。该查询为明文 HTTP 请求，会传输您的 IP。详见 ip-api.com 文档。
  • AI 内容审核服务：您提交的消息与回复全文将发送至我们配置的第三方 AI 服务进行内容安全审核。该服务位于境外。
  • SMTP 邮件服务：通过第三方 SMTP 服务发送邮箱验证、信件投递与回复通知邮件，邮件内容含收件人邮箱及消息摘要。

二、我们不会收集的信息

  • 不强制要求真实姓名、手机号、身份证号等真实身份信息（注册账号仅需电子邮箱）
  • 不做跨网站行为追踪，不建立商业用户画像
  • 不收集设备唯一标识符（如IMEI、MAC地址）
  • 不将数据用于广告推送或商业营销，不接入任何第三方分析或统计脚本
⚠️ 重要合规提示

鉴于本服务域名未完成ICP备案，且使用境外动态域名部署，本服务无法主动向中国大陆地区用户提供访问服务。若您身处中国大陆地区，请自觉退出本服务。因违反此规定使用本服务产生的任何法律风险，由用户自行承担。

三、信息使用目的

我们仅将收集的信息用于以下目的：

  1. 提供核心服务：在雨天向用户展示匿名消息、提供情感信件投递与回复功能
  2. 账号识别与会话保持：登录认证、维持登录状态
  3. 邮件通知：邮箱验证、信件投递通知、回复提醒
  4. 本地化展示：通过 IP 反查所在城市，提供对应天气状态与本地化内容
  5. AI 辅助内容安全审核：对消息与回复正文进行违规内容识别
  6. 保障服务安全：识别并阻止滥用行为（如垃圾信息、攻击、暴力破解）
  7. 服务优化：根据设备信息调整页面兼容性
  8. 法律合规：配合司法机关依法调取数据（如收到有效法律文书）

四、信息共享与披露

我们不会出售、出租或交易您的任何信息。仅在以下情况可能披露信息：

  1. 法律要求：根据适用法律、法规、司法或行政程序要求
  2. 安全防护：为防止欺诈、滥用或安全事件，向必要第三方提供有限信息
  3. 服务必需：向以下第三方服务提供商传输必要数据：
    • Cloudflare（人机验证）
    • 和风天气（天气数据查询）
    • ip-api.com（IP 地理定位）
    • 第三方 AI 内容审核服务（审核消息/回复正文）
    • 第三方 SMTP 邮件服务（发送通知邮件）
  4. 业务转让：如发生合并、收购或资产出售，用户信息可能作为转让资产的一部分

五、数据安全措施

我们采取以下措施保护您的数据：

  • 采用参数化查询（Drizzle ORM）防止 SQL 注入攻击
  • 对用户输入进行 XSS 过滤与 SQL 注入特征检测
  • 密码以 scrypt 单向哈希存储，不保存明文
  • 会话 Cookie 设置 HttpOnly 与 SameSite 属性，生产环境可选启用 Secure
  • 写操作启用 CSRF token 保护
  • 登录失败按邮箱与 IP 双维度锁定，防御暴力破解
  • 蜜罐字段与行为验证（页面停留、输入交互）防御自动化机器人
  • 敏感操作（如内容提交、登录）启用 Cloudflare Turnstile 人机验证
  • 未验证账号定时清理（注册后 60 分钟未验证邮箱即删除）
  • 服务器部署于受防火墙保护的网络环境，并设置安全响应头（CSP 等）

六、数据泄露应对

我们将采取以下措施应对数据泄露事件：

  • 应急预案：制定数据泄露应急预案，定期演练
  • 通知义务：如发生可能影响您权益的数据泄露，我们将：
    • 在知悉后72小时内评估影响范围
    • 如可能对您造成风险，将通过网站公告或邮件方式通知
    • 通知内容包括泄露性质、大致范围、建议采取的补救措施

七、数据存储与跨境传输

  • 所有数据存储于境外服务器
  • 由于服务部署于境外，您的信息可能被传输至您所在国家/地区以外的地点进行处理
  • 消息与回复正文在 AI 内容审核阶段会被传输至境外的 AI 审核服务端点
  • 您的 IP 地址会经 ip-api.com 进行地理定位查询
  • 我们将采取合理措施确保跨境数据传输符合相关法律要求

十一、Cookie与追踪技术

本服务使用名为 session 的 Cookie 维持您的登录会话与基础功能（如验证码校验状态）。该 Cookie：

  • 采用 HttpOnly 与 SameSite 属性保护，生产环境可选启用 Secure；
  • 有效期为 24 小时，仅用于身份识别与会话保持，不用于行为追踪或广告；
  • 内容由服务端 HMAC 签名，不存储明文敏感信息。

本服务不接入 Google Analytics、百度统计等任何第三方分析或统计脚本。若您在浏览器中禁用 Cookie，登录等需要会话保持的功能可能无法正常使用，匿名浏览功能不受影响。
